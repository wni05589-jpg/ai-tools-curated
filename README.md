## How I pick tools

1. **I actually use it** — no affiliate-pushed junk, no "featured" slots.
2. **It solves one job well** — I'd rather list 50 tools that work than 5000 that don't.
3. **It's current** — the AI space moves monthly; entries here are reviewed on a rolling basis.
